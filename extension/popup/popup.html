New API Codex OAuth 助手

真实授权 · 完整凭证 · 本地导出

1. 获取完整凭证

点击登录，在官方页面完成授权。请保持本页打开。插件不会读取网页 Cookie，也不会生成假的 token。

授权后浏览器会跳转到 http://localhost:1455/auth/callback。本插件不启动本地服务，因此页面可能显示“无法访问”。复制那一页地址栏中的完整网址，粘贴到这里即可。

请勿同时进行 Codex CLI 登录；回调网址只粘贴在本插件里。

已有 Codex auth.json？直接导入

支持 Codex 原生嵌套格式与 New API 平铺格式。文件仅在本页内处理；缺少 refresh_token 或带占位凭证的文件会被拒绝。

等待授权或导入。

2. 导出给 New API

已检查 access_token、refresh_token、id_token 与 account_id 的字段及基本结构；实际调用权限仍以 New API 的请求结果为准。


    
    
    
    
    
New API：新增/编辑渠道 → ChatGPT Subscription (Codex) → 将 New API JSON 的完整内容粘贴到密钥框。它不是 New API 的全渠道备份文件。

    
保存时请选择 D 盘。凭证只留在本页内存，刷新或关闭本页会丢失；下载后的文件请妥善保存。

    
交给 New API 后让它管理刷新，避免其他客户端同时使用同一份 refresh_token 进行轮换。

  

  
仅向 auth.openai.com 交换授权码；不自动上传到 New API 或其他服务。此插件为社区项目。
